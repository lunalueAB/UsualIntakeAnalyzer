================================================================
  일상섭취량 분석기 (UsualIntakeAnalyzer) — 빌드 & 실행 가이드
================================================================

■ 필수 조건
  - Windows 10/11 (WPF는 Windows 전용)
  - .NET 8 SDK  →  https://dotnet.microsoft.com/download
  - 인터넷 연결 (첫 빌드 시 NuGet 패키지 자동 다운로드)

■ 빌드 방법 (명령줄)
  1. 이 폴더(UsualIntakeAnalyzer/)를 원하는 위치에 복사
  2. 해당 폴더에서 PowerShell 또는 cmd 열기
  3. 아래 명령 실행:

     dotnet restore
     dotnet build -c Release
     dotnet run            (개발 실행)

     또는 배포 exe 생성:
     dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

■ Visual Studio 사용 시
  1. Visual Studio 2022 (17.x 이상) 열기
  2. [파일] → [열기] → [프로젝트/솔루션]
  3. UsualIntakeAnalyzer.csproj 선택
  4. F5 또는 Ctrl+F5 실행

■ 사용 순서
  ① DB 관리 탭으로 이동
     - [코드집] 섹션: codezip.xlsx 업로드
     - [x0 자료] 섹션: 국건영 2일 조사 CSV(국건영x0.csv) 등록
                        설명, 등록자 입력 후 "CSV 파일 선택 및 등록" 클릭
     - [x1 자료] 섹션: 국건영 1일 조사 CSV(국건영x1.csv) 등록

  ② 일상섭취량 분석 탭으로 이동
     - 왼쪽 패널에서 분석할 식품 선택 (복수 선택 가능)
       · 검색창에서 식품명 검색
       · 체크박스로 다중 선택
       · 선택 없으면 전체 코드 사용
     - 시뮬레이션 횟수 선택 (기본 5회)
     - "▶ 분석 실행" 클릭

  ③ 결과 확인
     - 📋 통계 결과 탭: 전체/성별/연령군 별 분위수 통계
     - 📈 밀도 그래프 탭: 1일 섭취량 vs 일상섭취 추정량 밀도 곡선
     - 🎯 분위수 도표 탭: 성별·연령군 별 P95/P97.5/P99/평균 점도표
     - "결과 내보내기(CSV)" 버튼으로 통계표 저장

■ CSV 파일 형식 (x0 — 2일 조사)
  헤더: (row_idx), id, sex, age, ageG, ageG_desc, day, region,
        wt_ntr, fcode, nf_intk, ffq, town_t, ho_incm, edu,
        genertn_type, region_type

  CSV 파일 형식 (x1 — 1일 조사)
  헤더: (row_idx), id, sex, age, ageG, ageG_desc, region,
        wt_ntr, fcode, nf_intk, ffq, town_t, ho_incm, edu,
        genertn_type, region_type
  (day 컬럼 없음. fcode가 있으면 행별 식품 데이터로 처리)

■ 알고리즘 개요 (NCI 방법)
  1. x0(2일 조사)에서 섭취 여부(eatP)·섭취량(eatA) 일간 Pearson 상관
     rhoP: papa < 5%면 0.95, 아니면 상관계수
     rhoA: 양일 모두 섭취한 사람의 섭취량 상관계수
  2. x1(1일 조사)로 시뮬레이션 (time회 반복):
     - Logistic GLM(binomial, logit): P(섭취) ~ ageG + ho_incm
     - Gamma GLM(log link): 섭취량 ~ ageG + ho_incm (양수만)
     - 개인별 52주 시뮬레이션 → 주 평균 일상섭취량 추정
  3. time회 평균 → 최종 일상섭취량
  4. 성별/연령군 별 분위수 통계 산출

■ 저장 위치
  데이터는 AppData\Roaming\UsualIntakeAnalyzer\에 저장됩니다.
  경로: %APPDATA%\UsualIntakeAnalyzer\
